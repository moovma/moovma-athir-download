# Moovma Athir

**Control Elyssa, the first Tunisian dev board, from your phone.**
Connect over Bluetooth or Wi-Fi, pick a ready-made interface (robot, drone / plane controller, motion sensor,
messenger, light), copy the matching code into the board, and go. Includes over-the-air (OTA) firmware updates.

## Download

**Android (APK):** [**Download the app (APK, 36 MB)**](https://github.com/moovma/moovma-athir-download/releases/download/v0.1.0/Moovma-Athir-0.1.0.apk)

How to install: open the downloaded `.apk`, allow "install unknown apps" for your browser or file manager when
Android asks, then tap Install. No account is needed and nothing personal is sent anywhere.

No Elyssa yet? Open **Settings > Preview mode** to try every interface with a simulated board.
